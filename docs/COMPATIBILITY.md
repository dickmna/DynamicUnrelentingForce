# Runtime compatibility

Dynamic Unrelenting Force 1.1.1 and the included Shout Progression addon 0.6.1 target Steam Skyrim 1.7.104 and SKSE64 2.3.1, with Address Library v13.

If you use Skyrim 1.6.1170, keep the older 1.1.0 release. You do not need this compatibility update, and the new DLLs are not intended for that runtime.

The standalone plugin and Shout Progression addon are mutually exclusive: install only one. The player archive contains runtime files and license notices; corresponding source and build instructions are published separately in this repository.
